# Agent Note: 会话树与枝签交互

Status: implemented

[English](2026-09-06-session-tree-and-clip-interactions.md) | 中文

## Problem

仅依靠原生历史继承的会话树无法组织独立的仅枝签工作或不携带上下文的新想法。DSH 重启后还可能从可见列表省略未提问会话，因此持久关系需要可读取的端点才能支持导航。重复的卡片控件和固定阅读空间也使窄面板更难浏览。

## Decision

每个新衍生会话都显式记录同 Workspace 内的组织父。只有 full-fork 继承 DSH 历史；clips-only 接收冻结的枝签 recall；blank 不接收历史或附件。空白模式拒绝已有模型上下文，不追加 recall。父字段保持可选读取以兼容已有记录；旧的仅枝签记录不根据可变 Clip 推测父会话。

Host 通过 `DerivedSessionStore` 持有关系校验与存储。按需端点读取 inspect 持久日志，使用 DSH 标题折叠，只返回元数据而不传输正文。Client 将端点与原生目录合并；原生元数据只有占位显示名时保留日志标题。打开未列出的端点前，Client 要求日志仍可读且属于当前 Workspace，再通过公开 Session API 接入原有身份。缺失端点保留显示但不可打开。没有当前会话时，面板展示 Workspace 已知关系。

卡片采用自然高度，只有溢出正文显示阅读控件。三个主按钮按内容宽度排列，次要操作使用 DSH 菜单与弹窗。至少选择两枚枝签时显示多选命令。回收站在搜索框旁独立显示名称。即时撤销反向执行回收或完整排序操作，不是持久历史，也不是覆盖并发编辑的事务。

集合读取、修改、排序、卡片呈现、启动表单与树坐标分别归属独立模块。dnd-kit 提供指针和键盘手势、碰撞检测、让位动画与拖动预览。Host 继续验证[排序记录](2026-08-30-compact-batch-commands-and-clip-ordering.md)中的完整集合与置顶分组规则。浏览器文案使用 BranchMark 语言字典。浏览器构建替换依赖的 `process.env.NODE_ENV` 常量，不提供 Node 全局变量的 factory 检查拒绝相关回归。

## Alternatives considered

**所有分支都使用原生 parent header。** 原生 parent 表达历史继承；赋给空白或仅枝签会话会错误描述模型接收的上下文。

**只使用原生可见列表构建树。** DSH 的未提问过滤会在重启后移除有效的持久端点。只读取插件关系也缺少当前标题，无法证明已删除端点可以打开。

**保留自行维护的指针释放监听器。** 它们重复维护手势处理，也没有集合需要的键盘排序和让位效果。dnd-kit 提供这些行为，插件保留领域规则。

**保留固定卡片高度与嵌套命令胶囊。** 短摘录会占用空白阅读区域，多选需要额外交互才能展开动作。自然高度和按需多选命令符合已确认的紧凑布局。

## Consequences

组织关系可以持久保存，同时不增加模型输入或伪造 DSH 历史继承。树加载时需要读取端点日志；普通卡片关系查询避免这些读取。关系存储与 recall append 仍是两个持久操作，没有跨系统事务。浏览器包包含拖动库，呈现仍与 Host、Client 编排分离。

[排序记录](2026-08-30-compact-batch-commands-and-clip-ordering.md)继续维护完整集合校验、独立置顶元数据、选择顺序与草稿引用恢复的依据；本记录持有卡片呈现和树导航。

## Verification

Host 测试通过真实 Session 服务记录三种模式并比较模型上下文预期，拒绝非法空白上下文与并发重复登记，保持来源事件不变，读取旧记录并处理缺失端点。Client 测试覆盖集合范围切换、多选可见性、语言切换、原生目录只有三个条目时的 12 节点树，以及持久身份的打开和拒绝。浏览器 factory 反例拒绝 Node 全局变量和未声明外部模块。隔离的 DSH Web Profile 验证真实持久分支和实际 provider 回答。
